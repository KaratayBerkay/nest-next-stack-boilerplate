# EmptyChatState

**Source:** [`EmptyChatState.tsx`](../../../../../next-js-boilerplate/src/views/messages/EmptyChatState.tsx)
**Used in:** [messages page](../page.md) (desktop layout, rendered in place of [ChatView](./chat-view.md) when no conversation is selected)
**Mobile equivalent:** none — mobile's single-column layout has no "nothing selected" desktop-split state to fill.

## Purpose

Static placeholder ("select a conversation") shown in the right-hand pane before any thread is
opened. No props, no state, no data dependency.
